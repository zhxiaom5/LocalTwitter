# Test Cases

本文件在功能实现前定义测试 case，作为本项目开发门禁。

## 单元测试

| 删除目录不删文件 | 已保存目录和真实文件 | 删除目录配置 | 数据库索引移除，真实文件仍存在 | 误删用户本地文件 | 单元 |
| Twitter 文件名解析 | 多种 `日期_id_标题` 文件名 | 调用作品解析函数 | 正确提取推文 ID、标题、日期、媒体类型 | 文件名含下划线、中文、特殊符号 | 单元 |

| 首页 Feed 随机加载性能 | SQLite 中有上万条视频作品 | 请求 `/api/feed?limit=30` | 先随机打散候选推主，再按推主抽取作品返回，避免 `ORDER BY RANDOM()` 全量作品排序 | 首页播放器首次打开长时间停在加载中 | 单元/集成 |
| 首页 Feed 跨推主随机性 | 多个推主各有连续入库的一批作品 | 请求首页 `/api/feed?limit=30` | 返回作品尽量覆盖多个推主，不因 work id 连续导致整页都是同一推主 | 上下滑长时间困在同一博主作品里 | 单元 |
