# LocalTwitter 开源发布设计

## 目标与边界

将 `7d6a07c` 的可构建源码整理为可公开发布的最小仓库；不带入日常工作区未提交内容、数据库、媒体、浏览器登录态、构建物或既有 Git 历史。开源许可证采用 MIT。

本次不发布 fnOS 安装包、不迁移用户数据、不包含任何真实账号或 Cookie，也不替代使用者遵守目标平台条款的责任。

## 实施方案

1. 在独立 worktree 中从干净提交创建 `open-source`，最终改为只有一个根提交的 orphan 分支，以排除原历史暴露面。
2. 删除跟踪的 Go 构建缓存；加强忽略规则，提供 `.env.example`，把个人路径、局域网地址和登录态默认值替换为通用示例或显式环境变量。
3. 提供 MIT `LICENSE`、README、用户指南、部署说明、安全策略与贡献指南；README 列出公开目录结构和本地最小运行路径。
4. 验收包括：工作树敏感文件/绝对路径扫描、Git 历史只有根提交、Go 测试、前端测试、生产构建、Playwright E2E、Git diff 审查，以及 GitHub 推送前的最终秘密扫描。
