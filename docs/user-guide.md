# LocalTwitter 用户指南

## 首次配置

1. 按 [README](../README.md) 启动服务后，打开 `http://localhost:8080`。
2. 进入“设置”，选择一个可写的数据库目录。服务会创建并迁移 SQLite 数据库。
3. 添加一个包含你有权访问的本地内容的目录。可从页面的目录浏览器选择，避免手工猜测服务器路径。
4. 在 Feed、作者或详情页浏览已索引的内容；目录扫描与更新状态会显示在页面中。

目录路径属于运行服务的机器，不是访问浏览器的客户端机器。不要把私有媒体、数据库或配置目录映射为 Web 静态目录。

## 更新和账号信息

若启用更新功能，Cookie、`auth_token`、`ct0` 和代理设置由服务端保存到本地 SQLite 数据库；它们不会写入源码、日志或导出的诊断信息。请仅使用自己的授权账号信息，并定期删除不再需要的凭据。

不要将以下内容粘贴到 Issue、截图、仓库或聊天记录中：

- 浏览器 Cookie JSON、Token 或账号会话；
- 本机/局域网地址、下载目录和数据库文件；
- fnOS Playwright `storageState` 文件。

## 常见问题

- **页面没有内容**：确认已添加目录，目录对运行服务的用户可读，并等待扫描完成。
- **无法写入数据库**：在设置页选择可写目录；不要将数据库放在只读打包资源中。
- **需要迁移服务器**：停止服务，复制你的 SQLite 数据库和媒体目录到目标机器，再在新服务中配置对应路径。它们不属于 Git 仓库。
- **登录态过期**：用 fnOS 部署脚本重新执行 `--login --headed`。生成的登录态文件必须保持在忽略的 `.local/` 目录或其他私密位置。
